# Sprint_7
# Автотесты для API сервиса заказа самокатов

##  Описание проекта
Проект содержит автоматизированные тесты для проверки API учебного сервиса «Самокат»:
- Создание курьера
- Логин курьера
- Создание заказа
- Получение списка заказов

##  Структура проекта
Sprint_7/
├── tests/                          # Тестовые файлы
│ ├── test_courier_creation.py      # Тесты создания курьера
│ ├── test_courier_login.py         # Тесты авторизации курьера
│ ├── test_order_creation.py        # Тесты создания заказа
│ └── test_orders_list.py           # Тесты списка заказов
│
├── data/                           # Тестовые данные
│ └── orders_data.py                # Генерация данных для заказов
│
├── conftest.py                     # Фикстуры pytest
├── constants.py                    # URL и константы
├── courier_generate_method.py      # Методы для создания курьеров
├── requirements.txt                # Зависимости проекта
├── .gitignore                      # Игнорируемые файлы
├── allure-results                  # Сгенерированный отчет
└── README.md                       # Документация проекта

##  Тестируемая функциональность

### 1. Создание курьера (`POST /api/v1/courier`)
- **Тест 1:** Успешное создание курьера с валидными данными
- **Тест 2:** Невозможность создать двух одинаковых курьеров
- **Тест 3:** Создание курьера только с обязательными полями (логин и пароль)
- **Тест 4:** Ошибка при отсутствии логина (параметризован)
- **Тест 5:** Ошибка при отсутствии пароля (параметризован)
- **Тест 6:** Ошибка при создании курьера с существующим логином

### 2. Логин курьера (`POST /api/v1/courier/login`)
- **Тест 1:** Успешная авторизация с существующими логином и паролем
- **Тест 2:** Ошибка при отсутствии логина (параметризован)
- **Тест 3:** Ошибка при отсутствии пароля (параметризован)
- **Тест 4:** Ошибка при неправильном логине (параметризован)
- **Тест 5:** Ошибка при неправильном пароле (параметризован)
- **Тест 6:** Ошибка при авторизации несуществующего курьера

### 3. Создание заказа (`POST /api/v1/orders`)
- **Тест 1:** Создание заказа с цветом BLACK (параметризован)
- **Тест 2:** Создание заказа с цветом GREY (параметризован)
- **Тест 3:** Создание заказа с двумя цветами (параметризован)
- **Тест 4:** Создание заказа без указания цвета (параметризован)

### 4. Получение списка заказов (`GET /api/v1/orders`)
- **Тест 1:** Получение списка заказов (проверка структуры ответа)

## Используемые технологии
Python 3.14
pytest 9.0.2 — запуск тестов
requests 2.31.0 — отправка HTTP-запросов
allure-pytest 2.15.3 — генерация отчетов
pytest-cov 7.0.0 — оценка покрытия кода

## Особенности реализации
- Все тесты независимы и не влияют друг на друга
- Тестовые данные создаются перед каждым тестом и удаляются после
- Используются фикстуры для переиспользования кода
- Параметризация для покрытия множества сценариев
- 100% покрытие кода тестами
